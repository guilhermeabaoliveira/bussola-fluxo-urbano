APRESENTAÇÃO · BLUEPRINT · MODELO 3D · EXPLAINER

O projeto no seu notebook.

Este pacote leva os quatro materiais para o Acer Nitro ou outro computador da equipe. A visualização principal funciona localmente; não precisa manter o Dell ligado.

1. Abrir no Acer Nitro

  1. Copie o arquivo Grupo12-Maquete-Apresentacao-Privada.zip para o Acer por pendrive ou pelo Drive.
  2. No Explorador de Arquivos, clique com o botão direito no ZIP e escolha Extrair Tudo. Não abra os HTMLs dentro da pasta compactada.
  3. Entre na pasta extraída e abra ABRIR.html no Edge ou Chrome. Se o Windows perguntar o aplicativo, escolha um desses navegadores.
  4. Escolha Apresentação, Blueprint, Maquete 3D ou Explainer. Os recursos ficam na própria pasta; não mova apenas um HTML para outro lugar.

Não é necessário instalar Blender, Python ou Arduino IDE para visualizar o conteúdo. O PPTX é uma opção para editar e apresentar no PowerPoint; o HTML dos slides continua disponível mesmo sem esse programa.

2. Compartilhar somente com os colegas

  1. Crie uma pasta dedicada no Google Drive e confira quem já tem acesso a ela.
  2. Envie o ZIP para essa pasta. Em Compartilhar → Acesso geral, mantenha Restrito.
  3. Adicione apenas as contas dos membros do grupo como Leitor. Eles precisam poder baixar o pacote para abri-lo localmente.
  4. Cada colega baixa o ZIP e segue os mesmos passos de extração. O Drive entrega o arquivo; ele não executa o visualizador 3D como um site.

Privacidade: a restrição controla quem baixa o arquivo pelo Drive. Depois do download, uma cópia local pode ser repassada; não existe revogação automática de um arquivo já baixado. Combinem a circulação somente entre os membros.

3. Controles para demonstrar

  • Apresentação: botões anterior/próximo, índice e tela cheia. Use as setas do teclado.
  • Blueprint: escolha uma etapa, execute o exemplo ou manipule os alvos. Acompanhe a janela de 10 segundos e abra as peças no 3D.
  • Maquete: arraste com o botão esquerdo ou o botão do meio para girar; roda para aproximar; botão direito para deslocar. Clique em uma peça para isolá-la e ver sua descrição.
  • Explainer: use o sumário para consultar lógica, peças, dimensões e diagramas. O PDF de 10 páginas também está disponível nessa seção.
  • Ligações: use Abrir construção, a vista de baixo e o filtro de circuito. Voltar à montagem recupera a visão completa.

4. Antes de levar para a faculdade

Faça uma abertura no próprio Acer antes da apresentação: confira o modelo carregado, rode o exemplo A1/B3/C2 e abra um slide. Desconecte o Wi-Fi por um momento para confirmar que o pacote local está completo. Links voluntários de lojas e referências precisam de internet.

Se o 3D não aparecer, confira se os arquivos foram extraídos e tente o outro navegador. A visualização precisa de WebGL funcionando. Enquanto isso, os slides incluem vistas renderizadas para explicar a montagem.

E um site privado, aberto por link?

É possível, desde que uma hospedagem proteja todas as páginas e os arquivos do modelo com autenticação antes de entregá-los. Uma senha escrita no JavaScript ou um endereço difícil de adivinhar não substitui esse controle. Este pacote não foi publicado na internet.

O GitHub Pages padrão publica um site estático, mesmo quando o repositório de origem é privado. A opção privada do Pages é específica de organizações com GitHub Enterprise Cloud. Como o requisito é acesso apenas ao grupo, não usamos Pages público para esta entrega.

Sites estáticos como estes não precisam de PHP. O GitHub Pages não executa PHP no servidor; portanto ataques que dependem de um PHP vulnerável não se aplicam a essa arquitetura. Isso é diferente de garantir segurança absoluta de uma hospedagem.
