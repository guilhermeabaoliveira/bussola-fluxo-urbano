# Publicação e segurança

O portfólio é estático: HTML, CSS, JavaScript e modelos locais. Não executa PHP nem precisa de banco, chaves ou credenciais. Isso reduz a superfície de ataque, mas não substitui atualização de dependências e revisão dos arquivos publicados.

Não incluir backups, histórico privado de chats, gravações pessoais, chaves, arquivos de configuração de contas, dados de alunos ou links privados de compartilhamento. E-mails dos integrantes não são necessários no portfólio.

A publicação no GitHub Pages torna os arquivos publicados acessíveis ao público. Um repositório privado não deve ser entendido como controle de acesso automático ao site. O pacote atual foi preparado localmente; publicação e disponibilidade pública devem ser verificadas separadamente.

Nenhuma credencial deve ser inserida no JavaScript. A coleta de dados de visitantes ou de pessoas no parque não faz parte desta demonstração. Fotos e imagens exigem conferência de direitos e consentimento quando aplicável.
